📋 Overview
Poli Security Toolkit is a collection of security-related utilities designed to help security researchers understand various attack vectors and protection mechanisms. The toolkit provides an interface for exploring cybersecurity concepts in a controlled environment.
🛠️ Features
Core Functions

Rar Logs Searcher: Searches your Logs from RAR files (you have to unzip it)
Text File Searcher: Search through text files for specific keywords
Combo Cleaner: Clean and optimize combo lists by removing duplicates, fixing reversed lines and removing URL.

Username Research

Username Search: Check username availability across multiple platforms

Proxy Management

Proxy Harvester: Collect proxy lists from various sources
Proxy Checker: Verify proxy validity and functionality

Discord Tools

Token Checker: Verify Discord token validity
Token Generator: Generate sample Discord tokens for testing
Discord Nuker: Server guard tester that nukes your server

Checkers

Hotmail checker: Checks if your account on hotmail is valid.

Developer Mode Only
